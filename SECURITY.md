# Security / Responsible Disclosure

This repository documents security research and forensic analysis.

It intentionally does not publish:
- private keys
- credentials
- authentication/session secrets
- uncontrolled production bundles
- private user data
- local runtime secrets

The public repository is a curated evidence corpus.

A finding should not be treated as a confirmed vulnerability solely
because a script, trace or artifact appears in this repository.
Claims should be supported by:
1. a clearly stated hypothesis,
2. reproducible evidence,
3. affected boundary or behavior,
4. impact analysis,
5. and explicit limitations.

If potentially sensitive material is discovered in the repository,
do not reproduce it publicly. Report the file/path and the nature of
the exposure so it can be removed or replaced with a sanitized artifact.
